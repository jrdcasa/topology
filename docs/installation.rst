Installation
============

To install ``topology`` from source:

.. code-block:: bash

    git clone https://github.com/jrdcasa/topology.git
    cd topology
    pip install -e .

Dependencies
------------

Make sure you have:

- Python 3.8+
- numpy
- any other dependencies your project uses

``topology`` should now be importable:

.. code-block:: python

    import topology
